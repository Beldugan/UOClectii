# Materialele ședințelor · FIMIM UOC · sem. I 2026–2027

Site: https://beldugan.github.io/UOClectii/

- `index.html` – lista ședințelor pe program (AR II, AR III, AR IFR, AR IV; IAII fără pachete), disciplină/subgrupă și săptămână.
- `o.html?o=<id>` – pagina unei ședințe: PDF-ul afișat direct, „Descarcă PDF”, „Printează”, „Ecran complet”, navigare între ședințe.
- `pdf/` – pachetele generate (copertă + paginile din îndrumarul de laborator / de proiect).
- `files/` – fișiere de lucru (foaia de calcul PCMAI).
- `data/ore.json` – legătura dintre evenimentele din Google Calendar și pachete.
- `build/build.py` – scriptul care reface pachetele din îndrumare.
